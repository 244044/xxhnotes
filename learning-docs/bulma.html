一、常见的布局

1、block类：基本的 间隔块（兄弟元素之间会有间距）
2、box类：简单的容器（具有白色背景 + 阴影）
可以添加其他标签

3、content类：当你无法使用想要的CSS类,或者仅仅想直接使用HTML标签时,请使用 content作为容器只想使用标签，不使用样式

它几乎可以处理任何HTML标签:p段落、ul、ol、dl列表、h1到h6标题、blockquote引言、em、strong、table、tr、th、td表格
官方文档：https://bulma.io/documentation/elements/content/

5、响应式

  • (1)、from() 和 until() 混合类

    • @mixin from(1200px): 宽度大于等于（>=）

      Sass: @use "bulma/sass/utilities/mixins";
      .my-element {
      background: red;
      @include mixins.from(1280px) {
      background: blue;
      }
      }

    • @mixin until(1200px): 宽度小于（<）[设置屏幕宽度（减去1px）]

      Sass: @use "bulma/sass/utilities/mixins";
      $breakpoint: 1280px;
      .my-element {
      @include mixins.until($breakpoint) {
      background: green;
      }
      @include mixins.from($breakpoint) {
      background: orange;
      }
      }

    (2) 命名简称

    • mixins.mobile: <= 768px

      用法（以下类推）： @use "bulma/sass/utilities/mixins";
      @include mixins.mobile {
      // Styles applied // below $tablet }

      mixins.touch: 0 ~ 1023px(不包括1023px)

    • mixins.tablet： >768px(不包括768px，即：769px)

      mixins.tablet-only： 769px ~ 1023px

    • mixins.desktop： >=1024px

      mixins.desktop-only： 1024px ~ 1215px

    • mixins.widescreen： >=1216px

      mixins.widescreen-only： 1216px ~ 1407px

      mixins.until-widescreen： 0 ~ 1407px（不包括1407px）

    • mixins.fullhd： >=1408px
